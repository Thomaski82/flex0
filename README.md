# Flexo

Interaktywny prototyp aplikacji do krótkiej pracy dorywczej, inspirowany modelem Stint i dostosowany do polskiego rynku.

## Uruchomienie

Otwórz `index.html` bezpośrednio w przeglądarce albo uruchom lokalny serwer:

```powershell
python -m http.server 4173
```

Następnie przejdź do `http://localhost:4173`.

## Zakres MVP

- wyszukiwanie i filtrowanie krótkich zmian,
- szczegóły stanowiska i wynagrodzenia,
- zapis i anulowanie zapisu,
- trwałe zapisanie zmian w `localStorage`,
- kalendarz zmian, portfel i profil pracownika,
- responsywny interfejs desktop/mobile.
